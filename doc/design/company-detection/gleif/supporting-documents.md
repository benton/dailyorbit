# GLEIF Supporting Documents

Official specifications, schemas, sample files, and policy documents.
All freely available from gleif.org.

the full 455MB golden copy.

## Schema Transformations (XSLT)

For backward compatibility with older CDF versions:

| Transform | Purpose |
|-----------|---------|
| LEI-CDF 3.1 -> 2.1 | Downgrade Level 1 format |
| RR-CDF 2.1 -> 1.1 | Downgrade relationship format |
| RepEx 2.1 -> 1.1 | Downgrade exceptions format |
| [XSLT documentation (PDF)](https://www.gleif.org/en/lei-data/access-and-use-lei-data/supporting-documents) | Technical guide |
